Methodology

How to use this dashboard:

Required file: activities.csv
Export the first-booking activities from your CRM (contains creation and booking dates).

  • Upload a CSV file containing the columns:
    • Deal/activity creation date:
      • ta_created_at (CRM activities)
      • deal_created_at (deals)
      • created_at
      • data_criacao
    • Booking/meeting date:
      • data_do_agendamento (CRM)
      • data_da_call (CRM)
      • first_schedule_date
      • data_primeiro_agendamento
      • primeira_reuniao
    • Columns for AI detection:
      • sdr (SDR email) - to detect +123 or +789
      • user_email (user email) - alternative
      • contact_tags (contact tags) - to detect AI tags
    • Optional columns: deal_id, contact_id, origin_name, deal_status, type

Automatic processing:

  • Automatic filtering: only records with valid dates
  • Removal of negative intervals (booking before the deal/activity)
  • Outlier removal using the 99th percentile (P99)
  • Automatic detection of AI bookings:
    • SDR emails containing +123 or +789
    • Tags: "agendado ia", "tentativa ia", "tentativas esgotadas ia", "agendado ligação ia", "ligar depois ia", "reunião removida - ia", "fora do icp - ia", "agendado whatsapp"
  • Automatic calculation of: median, quartiles, distributions and time trends
  • Compatible with CRM activity CSVs (columns ta_created_at, data_do_agendamento)
  • Global date filter - set the analysis period you need
