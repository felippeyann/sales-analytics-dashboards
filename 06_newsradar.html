Metodologia - Dashboard Editorial NewsRadar

Como usar este dashboard:

Arquivo necessário: activities.csv
Exportar atividades da base de artigos do sistema.

  • Faça upload de um arquivo CSV contendo artigos com as seguintes colunas:
    • Obrigatórias:
      • título ou title ou headline - Título do artigo
      • data ou date ou publicado_em - Data de publicação
      • fonte ou source ou publisher - Fonte/veículo
    • Opcionais:
      • score ou relevância - Score de relevância (0-100)
      • url ou link - Link do artigo
      • tags ou keywords - Palavras-chave (separadas por vírgula ou lista)
      • categoria ou category - Categoria editorial

Funcionalidades principais:

  • Keyword Explorer: Análise de palavras-chave com nuvem, grafo e heatmap
  • Theme Evolution: Evolução de temas ao longo do tempo
  • Source Analysis: Performance por fonte/veículo
  • Sankey Flow: Fluxo de keywords → fontes → artigos
  • Insights IA: Análises contextualizadas via Google Gemini

Processamento automático:

  • Tokenização inteligente: Remove stopwords e normaliza termos
  • Detecção de keywords: Extração de título + tags
  • Análise de co-ocorrência: Relacionamento entre palavras-chave
  • Agregação temporal: Agrupamento por dia/semana/mês
  • Parseamento de datas: Suporta DD/MM/YYYY, YYYY-MM-DD e ISO
  • Stopwords em português: Filtragem automática de artigos, preposições, etc.

Visualizações disponíveis:

  • Keyword Cloud: Nuvem de palavras com frequência
  • Keyword Network: Grafo de relacionamentos entre termos
  • Keyword Heatmap: Matriz de co-ocorrência (top keywords)
  • Theme Evolution Heatmap: Evolução de temas por período
  • Source Bar Chart: Ranking de fontes por volume
  • Sankey Diagram: Fluxo de dados multi-dimensional
  • Latest Articles Table: Listagem completa com filtros

Filtros disponíveis:

  • Keyword filter: Filtrar por palavra-chave específica
  • Source filter: Filtrar por fonte/veículo
  • Date window: Últimos 7 dias, 30 dias, 90 dias ou todos
  • Top N: Ajustar quantidade de keywords exibidas (10-100)
  • Table filters: Busca em título, tags e score

Dicas de uso:

  • Use filtros ativos (chips ciano) para refinar análises
  • Clique em "" nos cards para insights de IA sobre cada visualização
  • Exporte dados limpos via "CSV Limpo"
  • Clique em nodes do grafo para aplicar filtro de keyword
  • Use Discord webhook para enviar resumos automaticamente

Notas técnicas:

  • 100% local: Nenhum dado é enviado para servidores (exceto IA/Discord quando ativado)
  • Performance: Otimizado para até 10.000 artigos
  • Limpeza automática: Remove registros sem título ou data
  • Timezone: America/Sao_Paulo (UTC-3)
